# Olist E-Commerce Dashboard

Interactive Power BI dashboard built using the Olist Brazilian E-Commerce dataset to analyze sales performance,
customer behavior, product trends, and delivery performance.

## Dashboard Pages

### Sales Overview
- Revenue and order analysis
- Monthly sales trends
- State-wise sales performance
- KPI tracking

### Customer Analysis
- Customer distribution analysis
- Retention insights
- Purchase behavior trends

### Product Performance
- Product category performance
- Revenue contribution by category
- Order volume comparison

### Delivery Analysis
- Delivery performance tracking
- Average delivery days
- Delivery insights across states

## Key Insights
- Most customers made only one purchase
- São Paulo recorded the highest customer orders
- Top product categories contributed the majority of revenue
- Delivery performance improved over time
